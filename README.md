# DSH 语音输入校对插件

为 DeepSeek Harness（DSH）的语音输入增加文字校对：先使用内置的 SenseVoice 在本地识别语音，再通过 DSH 中配置的模型优化识别结果。

## 与 DSH 内置语音输入的关系

本插件是内置语音输入的扩展，需要先启用 DSH 内置语音输入并准备好 SenseVoice 本地模型。它复用内置录音界面、本地识别器和模型资源，不提供独立的语音识别模型。

启用后，输入框中的语音按钮仍由 DSH 内置插件提供。识别和校对流程为：

```text
内置语音输入录音 → SenseVoice 本地识别 → 所选模型校对文字 → 插入输入框
```

本插件注册 `sensevoice-proofread` 语音提供方，将本地识别和文字校对串联起来；原有的 `sensevoice-local` 提供方仍可使用。切回原有提供方即可使用不经过校对的本地识别。

## 功能

- 从 DSH 已配置的模型中选择校对模型，选择后自动保存。
- 结合识别文字的语义，尝试修正同音错词、专业术语、标点和断句，并清理不影响意思的口头停顿和重复。
- 设置 10、20、30 或 60 秒的校对超时时间，默认 30 秒。
- 注册“开始或停止语音输入”快捷键，可在 DSH 快捷键设置中自行绑定；默认没有按键。

## 配置和使用

1. 在 DSH 中启用内置语音输入，并完成 SenseVoice 本地模型准备。
2. 安装并启用本插件，在插件设置中选择一个已配置的校对模型。
3. 点击“启用语音校对”，切换到带校对的语音提供方。启用后可在同一页面调整校对超时时间。
4. 在输入框点击语音按钮，或使用自行绑定的语音输入快捷键，录音完成后检查插入的文字。

如需关闭校对，可在 DSH 语音输入设置中切回 `sensevoice-local` 提供方。插件快捷键依赖当前版本内置录音控件的标签，DSH 界面更新后可能需要适配。

## 数据与隐私

录音由 SenseVoice 在本地识别，不会由本插件发送给校对模型。**识别出的文字会发送给所选模型的服务提供方**，其数据处理方式取决于该服务。当前插件不向校对模型提供对话历史；模型使用本次识别文字及校对提示词进行判断。

## 失败处理与使用限制

- 模型未配置、校对失败或超时时，插件返回本地识别原文，并记录不包含识别文字的警告日志。当前录音界面不会单独提示此次回退，请发送前检查文字。
- 校对模型只能看到识别文字，无法重新听取音频，不能保证纠正所有错误；人名、数字和其他关键内容应自行核对。
- 如果模型适配器忽略取消信号，超时后其后台请求仍可能继续运行。
- 修改插件宿主端代码后，需要重启 DSH 才能加载更新。
