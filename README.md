# 语音识别校对

使用 DSH 内置的 SenseVoice 本地识别语音，再通过所选模型校对识别文字。音频由本地识别；识别文字会发送至所选模型服务。

校对提示会要求模型结合上下文修正同音错词、断句和技术术语，按语义重建标点，并谨慎清理无意义的口头停顿和重复；保留有意义的强调、自我纠正以及不确定的人名、数字等内容。模型只能看到识别出的文字，无法重新听取音频，因此无法保证所有错误都能纠正。

在 DSH 的插件设置中选择并保存模型，然后点击“启用语音校对”。也可以通过配置指定 `provider` 和 `model`，并选择 `sensevoice-proofread` 语音提供方；模型未配置时会保留本地识别原文。插件注册了无默认按键的语音快捷键，可在 DSH 快捷键设置中绑定；它依赖当前版本内置录音控件的标签，DSH 界面更新可能使其失效。

可在插件设置中选择 10、20、30 或 60 秒的校对超时时间，默认 30 秒。修改插件宿主端代码后需重启 DSH 加载更新。

校对失败或超时时会返回本地识别原文；当前录音界面不会单独提示此次回退，发送前请检查文字。如果模型适配器忽略取消信号，其后台请求可能继续运行。
